# Model Comparison — Executed Results

Results are generated by `backend/scripts/train.py` and stored in `reports/model_comparison.json`. They use the same 17 precomputed feature columns, training-only standardization, grouped 80/20 holdout split, seed 42, and 0.5 decision threshold. Groups are hashed from all 111 predictor columns so duplicate predictor vectors stay in one partition. No hyperparameter tuning used the held-out partition.

The run used 46,916 training rows and 11,729 test rows. Exact class counts, confusion matrices, ROC points, and per-model metrics are in the JSON artifact and API. The current metrics are measured from the local dataset; they are not estimated.

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Bayesian Logistic Regression (Laplace) | 0.8207 | 0.8651 | 0.7826 | 0.8218 | 0.9122 |
| Logistic Regression | 0.8207 | 0.8651 | 0.7826 | 0.8218 | 0.9122 |
| Linear SVM | 0.7734 | 0.8798 | 0.6614 | 0.7551 | 0.8950 |
| CART Decision Tree | 0.8476 | 0.8473 | 0.8680 | 0.8575 | 0.9304 |
| Random Forest (12 trees) | 0.8375 | 0.8302 | 0.8704 | 0.8498 | 0.9225 |

The current grouped holdout favors the CART tree on the listed metrics, but one split is not sufficient to declare a general best model. Evaluation does not establish live URL predictive validity because source extractor parity is unverified. The dataset is nearly balanced; no resampling or class weighting was applied. The linear SVM uses a sigmoid transform of its margin for displayed scores; those scores are not calibrated probabilities. ROC-AUC uses the native decision margin.

Hyperparameters: Bayesian logistic prior standard deviation 2, Laplace Hessian posterior; standard logistic L2 penalty 1; linear SVM hinge subgradient, L2 coefficient λ=0.03, 18 epochs; CART maximum depth 7, minimum leaf size 40; random forest 12 bootstrap trees, depth 7, minimum leaf size 40, sqrt feature sampling. Scaler mean and standard deviation are fitted only on training rows. Model threshold is 0.5.
